## 2. 生产流水线（他 2026-07 公众号亲口拆解，走过 9 遍）

1. **调研** — 把领域拆成互不重叠的板块，先搭知识树骨架看全貌，再派多个 Agent 并行填枝条
2. **规划** — "能列出有逻辑的大纲 = 入门的验收标准，列不出说明还在门外"
3. **多 Agent 并行写作** — 拆成一支队伍分头写（LLM 橙皮书 = 7 个 Agent 同写 7 章），作者当主编
4. **独立审校 + 事实核查** — 审校必须换独立 Agent，写的人不审自己的稿；数据参数必回查一手源。"这步是橙皮书不翻车的命门"
5. **构建发布** — 拼 PDF 发出去才算消化完。"知识只待在脑子里等于不能复用"

## 3. 心智模型（三重验证：跨领域出现 / 可预测立场 / 有排他性）

- **封装即杠杆** — "真正的杠杆，是把一种能力封装成谁都能一键调用的东西"。书、skill、专家都是同一件事的不同出口
- **地图先于知识点** — 高手和新手的差别在脑中有没有组织好的结构图，不在记住多少知识点；进陌生领域先画地图
- **开源与收益不矛盾** — 免费开源 → 微信读书收益 + 出版 + 影响力，"真做出对别人有用的东西，回头总会以别的方式回报"
- **做出来比说出来有用** — 实践检验，追新即写（AI 编程每冒出新东西就写一本，3 个月 9 本）
- **判断力 > 生成力** — 全部产品 AI 生成，本人只出产品思维和决策
