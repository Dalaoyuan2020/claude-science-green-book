前四天讲清了「为什么用、怎么装、怎么省钱」。从这一篇起，软件真正摆在你面前。这篇不急着教操作，先带你把它的结构看透：它长什么样、由哪几层组成、每层管什么。看懂骨架，后面每个功能落在哪，你心里都有数。

01

PART


先问它一句：你到底是什么？

WHAT · 让工具自己开口

认识新工具，最好的开场是让它自己说。我直接问 Claude Science「你是什么、有什么功能」，它答了这么一段：

— 它的自我介绍：面向科研的 AI 工作平台

它把自己定义成一句话：Anthropic 推出的、面向科学研究的 AI 工作平台。不是对话机器人，而是自带完整计算环境、能编程执行、能连学术数据库、支持多智能体协作，一个会话窗口就能从数据获取、分析、建模做到论文图表。内置 Python / R / Bash，pandas、numpy、PyTorch 开箱即用。

用大白话给它兜底：它是一张会自己动手的科研工作台，底子是 Jupyter Notebook。别把它当聊天框，把它当一张桌子：桌上有项目、有工作区、有产出。下面从最外层的桌面开始，一层层往里看。

02

PART


最外层：项目管理主页

HOME · 软件的大门

双击进来第一眼就是它，管的是你有哪些研究、最近在忙什么。

— 项目管理主页（①②③④）

1

Projects 项目区：一个研究方向一个项目，对话、文件、记忆各自独立，互不干扰。

2

Recent sessions：按时间排的「最近打开」，一点回到上次那场对话。

3

+New project：开新课题就点它，建议一个真实方向单开一个。

4

搜索 ＋ 资源库：全局搜历史，和跨项目通用能力的入口。

💡 第一次用别急着新建，先点进带 Example 标签的示例项目翻一翻，看一个完整研究长什么样。

进入项目：三栏工作台

DESK · 左中右三栏

点开会话，界面变成真正干活的样子：左中右三栏，这是你今后花时间最多的地方。

— 项目内三栏工作台（①②③）

1

左栏 · 会话与文件：New / Customize / Files / 历史，管「这个项目里的事」。

2

中栏 · 对话主战场：你发指令、它铺过程；底部有 Reviewer 审查条、Notebook 入口、输入框（@产出物 #会话 /技能）。

3

右栏 · 产出物预览：AI 产出的图、表、文稿当场预览、下载，不用去文件夹翻。

左边挑事情 · 中间干活 · 右边收成品

PART


功能菜单：调 AI 干活的方式

SWITCH · 不在顶部，在底部

有一圈开关管「AI 用什么方式帮你干活」。注意它们不在顶部，而是围着底部的输入框，很容易被忽略。分两处，共 7 个。

✦ 第一处：输入框正上方的状态行

— 状态行：①子代理 ②Notebook ＋ 左下 ⊟ 功能按钮

① active subagents 后台子代理计数，数字大于 0 说明在忙重活，别打断；② Notebook 点开在右栏跑 Python/R，画图跑模型直接出结果。

✦ 第二处：点 ⊟ 按钮弹出的菜单

— 输入框左下 ⊟ 按钮弹出的五个开关

1

Delegation 任务委派：把复杂任务拆成并行轨道，大任务再开。

2

Auto-review 自动审查：建议常开。独立审查员帮你核对数值对不对来源、引用撑不撑结论、DOI 是否一致。

3

Memory 记忆：建议常开。存主题、目标期刊、写作偏好，本地存储不外传，默认关记得手动开。

4

Specialist 专家角色：写方法学选统计学家、审稿切 Reviewer，用到再切。

5

Compute 计算位置：默认 Local，未发表数据只在自己电脑上跑，最稳。

再往里＋一张小抄

SETTINGS · 下一章讲透

主页、三栏、功能菜单，是日常打交道的三层。再深一层是设置中心：技能、连接器、权限、存储、用量、账号……每页管一类深度配置。和前面不同，这些子页不带底部那圈功能菜单，它们是「配置」不是「干活」。配一次长期受益，下一章专门讲透。

✦ 开机就这么设（小抄）

开关 推荐 理由
Auto-review ✅ 开 自动挡错，投稿前的保险
Memory ✅ 开 不用反复交代背景，本地不外传
Notebook 熟悉它 核对数值、复用代码全靠它
Delegation 大任务开 省 token 和响应时间
Compute Local 未发表数据不出你的电脑

— 一张图记住整个界面

由外到里认准四层：主页挑项目 → 三栏干活收货 → 输入框那圈开关调方式 → 设置中心深配置。先把 Auto-review 和 Memory 打开，你就站在一个靠谱的起点上了。下一章进设置中心，把这台工作台真正调成你自己的。
