> 科研零基础不用慌，人人都能发 SCI。
> 用 Claude Code 跑通「选题 → 文献 → 写作 → 审稿 → 投稿」全流程的实战手册。

## 这本书写给谁

1. **零基础研究生** — 导师放养、不知从哪下手
2. **非科班发文者** — 医生 / 工程师 / 教师，有数据有场景但不会写论文
3. **老手提效** — 已会写论文，想把重复劳动交给 AI

## 凭什么写这本书

不是理论推演。本书全部方法来自一篇真实 SCI 论文**从被拒稿到改投国际期刊成功提交**的完整实战，以及一套跑通的科研 Skill 工具链（文献检索、论文版本管理、模拟审稿人、引用格式转换、投稿前体检）。每一章背后都有真实的坑。

## 诚实边界

AI 不造数据。本书教的是把科研流程中的机械劳动交给 AI、把质量关口做成流水线——提效的是流程，不是学术造假。所有涉及数据、引用的环节，事实核查回一手源是不可跳过的命门。
