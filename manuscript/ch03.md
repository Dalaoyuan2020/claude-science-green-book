# §03 第一个任务：30 分钟摸清一个方向

## 一、你是不是也这样

研一开学第三周，导师给你指了个方向，原话是："你先看看轻量化工业异常检测，下次组会聊聊。"然后他就消失了。你打开知网和 Google Scholar，搜出几千条结果，挑了 30 篇看起来厉害的存进收藏夹。三周过去了，第一篇的引言你读了四遍，每个单词都认识，连起来不知道它想干嘛。组会前一晚，你盯着收藏夹里 30 个没打开过的 PDF，开始怀疑自己适不适合读研。

先说结论：这不是你的问题。让一个新手靠逐篇读论文来了解一个方向，就像让一个第一次进城的人靠挨条街走来认识这座城市——走三天，你只熟悉了三条街，还是不知道城市长什么样。

更扎心的是，你的痛苦大部分花在了不该人干的活上。判断一个方向值不值得做，需要的是全局信息：这个方向有几个门派、哪年开始火、主场期刊是谁、还有什么没人做。这些信息散落在几百篇论文的标题、摘要、引用数里，靠人肉一篇篇攒，攒一个月也攒不齐——但对机器来说，这就是几次数据库查询加一轮统计的事。

高手是反过来的：先搞一张全城地图，看清哪里是商业区、哪里是老城区、哪条路通向哪，然后才决定去哪条街深挖。这一章要教你的，就是让 Claude Code 在 30 分钟内帮你把这张地图画出来。前提只有一个：你已经按 §02 把 Claude Code 装好、能正常对话。你不需要写任何代码——接下来的四段话，逐段复制给它就行，查询、统计、存档全是它的事，你只负责看结果、做判断。

## 二、你现在在这里

先看清楚这件事在整个科研流程里的位置：

| 阶段 | 干什么 | 本书章节 |
|---|---|---|
| **① 摸清方向** | 画地图、找窗口、定选题 | **§03 ← 你在这里** |
| ② 吃透文献 | 建文献库、AI 帮你读 | §04 |
| ③ 做研究写论文 | 版本管理、写作、成稿 | §05/§07/§08 |
| ④ 投稿发射 | 拷打、打包、提交 | §06/§09/§10 |

摸底做得好，后面每一步都省力；摸底跳过去，你会在第三个月发现自己做的东西五年前就有人做了。这一步值 30 分钟。

走完这四步，你手里会多出四样东西：一份按分量排序的文献清单（抓 50 条记录，去掉重复后是 48 篇，后面会讲为什么有重复）、一张流派地图、一组能在组会上报出口的统计数字、一页带"窗口分析"的摸底报告。而且全程留了底——每一步的查询命令和原始结果都存了档，任何一个数字被导师追问，你都能指回出处。

## 三、手把手：四步画出领域地图

下面用"轻量化工业异常检测"当例子——就是给工厂产线上的"AI 质检员"瘦身：模型既要看得准（漏掉缺陷要赔钱），又要跑得快、装得进产线旁边那种小算力盒子。你换成自己的方向，把 prompt（提示词，就是你打给 AI 的那段话）里的方向名换掉即可。

全流程数据来自 OpenAlex——一个免费开放的学术文献数据库，不用注册、不用交钱，Claude Code 可以直接查它。你可能会问：为什么不用知网或 Google Scholar？因为那两个是给"人拿眼睛看"设计的，机器批量查询要么被墙要么被封；OpenAlex 是给"程序来查"设计的，一次能整整齐齐地吐回几十篇的标题、年份、引用数，正适合让 AI 干活。以下所有输出都是真实运行结果，实测于 2026-07-04。

还有个小问题先解决掉：你的方向是中文的，检索得用英文。别自己硬翻，开工前先甩给 Claude Code 一句——"我的研究方向是 XXX，帮我想 3-5 个英文检索词，说说各自的宽窄差别"——挑一个不宽不窄的再进第 1 步。

### 第 1 步：拉文献——对付"搜出几千条不知道看哪条"

这一步解决的是：把"几千条搜索结果"变成"按分量排好序的 50 条"。复制这段给 Claude Code：

```
我想摸清"轻量化工业异常检测"这个研究方向。请用 OpenAlex 的免费 API
（不用注册，带上我的邮箱 xxx@xxx.com——记得换成你自己的——走礼貌通道
更稳定），检索 2021 年以来的文献：
- 只在标题和摘要里搜（用 title_and_abstract.search 过滤器），检索式必须是：
  完整短语 "industrial anomaly detection"（带引号，不许拆词）
  AND (lightweight OR efficient OR real-time OR edge)
- 按引用数从高到低取前 50 条
- 列出每条的：标题、年份、期刊/会议、引用数
- 把原始查询命令和返回结果都存档到一个文件夹，后面几步还要用
```

换自己的方向时，照这个骨架改：你方向的核心名词做成带引号的完整短语，你关心的侧面（轻量化、可解释、小样本……）做成 OR 串。为什么检索式要写得这么死？这是用真金白银的时间换来的。实测时我们先试了宽泛搜索（同样限定 2021 年起、按引用排序），OpenAlex 返回 25,331 条结果，排前面的全是 6G 通信、元宇宙、物联网的综述——因为宽搜索把"lightweight""industrial""anomaly"三个词拆开了，谁沾边都算。拷打复核时还试了两种"差一点"的写法：四个词都放进标题摘要搜但不带引号，704 条，前排全是网络入侵检测；只搜完整短语不加搭配词，866 条，榜首直接换人。只有上面这个"完整短语+搭配词"的写法，命中收到 269 条，前 15 篇全部回到工业异常检测本行（其中还混着两篇时序"假同行"，第 2 步会让它们现形）。

真实返回的头几条长这样（实测于 2026-07-04）：

```
年份   引用   标题
2024   268   EfficientAD: Accurate Visual Anomaly Detection at Millisecond-Level Latencies
2023    88   PNI: Industrial Anomaly Detection using Position and Neighborhood Information
2024    53   MFGAN: Multimodal Fusion for Industrial Anomaly Detection Using ...
2023    52   EasyNet: An Easy Network for 3D Industrial Anomaly Detection
2023    42   FAPM: Fast Adaptive Patch Memory for Real-Time Industrial Anomaly Detection
```

看到没有，全场引用最高的那篇（268 次）把"毫秒级延迟"直接写进了标题。行情一目了然：这个方向的军备竞赛已经从"更准"卷到了"更快更小"。这个判断你原本要读几十篇论文才敢下，现在第一步就浮出来了。

先打一针预防针：你跑出来的条数、引用数、名次，跟书里对不上是**正常的**。数据库每天都在长，引用数每天都在涨，Top 50 的成员隔几个月就会换几张面孔；后面让 AI 划流派，划成 5-8 个也都正常。要看的是模式——哪年爆发、谁是门派、窗口在哪——不是具体数字。本章的数字只是 2026 年 7 月 4 日那天的快照。

顺带解释 prompt 里的"礼貌通道"：OpenAlex 官方规矩，查询时带上你的邮箱，就进入更快更稳的服务通道（polite pool）。不带也能用，但高峰期容易慢和抽风。另外就算走了礼貌通道，连续查询偶尔也会撞上一次"429"（请求太频繁的提示），不是坏了，让 Claude 等几秒重试就好——拷打复核时就撞上过一次，6 秒后重试成功。

### 第 2 步：画地图——对付"几十篇各说各话，看不出门派"

一个方向里的论文不是几十个孤立的点，而是三五个"门派"在打擂台。这一步让 AI 把门派划出来。复制这段：

```
基于第 1 步存档的那批文献：
- 先按标题去重——同一篇论文的 arXiv 预印本和正式版会算成两条记录，
  合并成一篇，保留引用高的那条。告诉我去重后剩几篇，后面都按这个数算
- 然后把这个方向划分成几个流派/分支：
  - 每个流派用一句话说清核心思路，说人话，我是新手
  - 每个流派列 2-3 篇代表作和引用数
  - 归类只准依据这批文献的真实标题和摘要，拿不准的就去查那篇的摘要
    确认，不许凭你的记忆猜
- 输出成一张 Markdown 表格
```

顺手说一句：这条 prompt 开头写"第 1 步存档的那批"而不是"刚才那批"，是留了后路——万一你中途关了终端，新开会话第一句让 Claude"读回第 1 步存档的文件夹"，就能无缝接着做，不用从头再查。

最后那条"不许凭记忆猜"不是客套。实测中就撞上一个例子：最高引的 EfficientAD，光看标题完全看不出门派，AI 顺手就想按印象归类。我们让它去查了这篇的摘要原文，白纸黑字写着"we then use a student–teacher approach"（我们采用师生网络方法），这才敢落进"蒸馏"那一格。让 AI 的每个结论都能指回原文，这是科研和聊天的分界线。

真实划出来的地图（实测于 2026-07-04，50 条记录去重后按 48 篇统计——PNI 和 EfficientAD 各有预印本+正式版两条）：

| 流派 | 篇数 | 核心思路（人话版） | 代表作（引用数） |
|---|---|---|---|
| 重建/生成类 | 9 | 让模型学会"画"正常品，哪里画不像哪里就是缺陷 | MFGAN(53)、AMI-Net(34) |
| 记忆库/特征嵌入 | 6 | 把正常品的特征存成一本"字典"，新样本来了逐页查 | PNI(88)、FAPM(42) |
| 蒸馏/师生网络 | 4 | 老师见多识广，学生只学过正常品；师生答案不一致的地方=异常 | EfficientAD(268) |
| 多模态/3D | 4 | 普通照片之外再加深度、点云、红外，看单眼看不出的缺陷 | EasyNet(52)、2M3DF(16) |
| 大模型/零样本 | 2 | 借 CLIP、SAM 这类通用大模型的见识，不训练直接上岗 | IAD-CLIP、SAM-guided(16) |
| 归一化流 | 2 | 把正常特征"压"进一个标准形状，落在形状外的=异常 | UniFlow(7) |
| 时序/IoT 传感 | 8 | 同名不同界：检测的是设备信号曲线，不是产品图像 | TMANomaly(23) |

（7 派共 35 篇；其余 13 篇是通用框架、主动学习、光照增强这类暂不成派的散兵，未单列，35+13=48。你自己跑的时候，AI 划出的流派数和名字大概率跟这张表不完全一样——5-8 个、名字换个说法，都算正常，核对每派的代表作对不对得上原文就行。）

最后一行是个真发现：搜"工业异常检测"，会混进一批做设备传感器信号的论文——名字一样，社区几乎不往来。做图像质检的你如果引错了这批文献，审稿人一眼就看出你是外行。地图的价值就在这：不光告诉你城里有什么，还告诉你哪条街不是你要去的。

有了这张表，读论文的方式也变了。以前是排队读：读完第 1 篇读第 2 篇；现在是按门派抽读：六个正主门派各挑引用最高的那一篇（时序那派不是你的街，跳过），六篇下来，整个方向的骨架就在你脑子里了——这也是下一章"文献不用自己读完"的底层逻辑。

### 第 3 步：四维体检——对付"感觉很热，但说不出数"

组会上说"这个方向最近很火"，导师会问：多火？哪年开始火的？发在哪？这一步把感觉换成数字。复制这段：

```
给去重后的这批文献做个"体检"，统计四个维度：
1. 年份分布——哪年爆发，现在是上升还是退潮
2. 来源期刊/会议 Top10——这个方向的主场在哪
3. 高频关键词——大家都在卷什么词
4. 内容构成——方法创新、综述、应用落地各占几篇
每个维度先给数字，再用一句话告诉我这意味着什么。
```

真实体检结果（实测于 2026-07-04，去重后 48 篇口径）：

```
年份分布：2021:1 → 2022:3 → 2023:10 → 2024:21 → 2025:13（共 48）
  （2023 起爆发，2024 峰值；2025 的 13 篇引用还没长起来就已挤进引用榜，热度未退）

来源 Top：IEEE Trans. Industrial Informatics(3)、Neurocomputing(3)、Sensors(2)……
  另有 10 篇来源显示为空——多是 WACV/ICCV 这类顶会论文，数据库没填期刊字段

标题热词：unsupervised(5)、multimodal(5，算上连字符写法 6)、fusion(4)、
  lightweight(4)、teacher/student(3)、memory(3)、reconstruction(4)

内容构成：方法创新 41 篇 / 应用落地 5 篇 / 综述 2 篇
```

四行数字，组会三连问全接住了：方向在上升期（不是接盘夕阳方向）；期刊主场是 IEEE 工业系列，但最强的方法都发顶会（顶会：计算机学科的顶级学术会议，在这个学科里分量常常比期刊还重、也更难中）；"无监督"（只给正常品照片、不标缺陷也能学）是全行业底色；八成半的论文在卷方法，写真实产线落地的只有 5 篇。

### 第 4 步：摸底报告——对付"信息都有了，组会上说不成话"

零散的表格带不进组会，你需要一页纸。复制这段：

```
把前三步的结果汇总成一页"方向摸底报告"，存成 Markdown 文件，包含：
- 这个方向的一句话定位，讲给外行也能懂
- 流派地图表格
- 热点判读
- 可能的窗口——必须从上面的数据推出来，每条注明依据，不许拍脑袋；
  写之前先回这批文献里查一遍有没有人已经在做，有就如实写上
存好后把文件路径告诉我。
```

注意我们说的是"窗口"不是"空档"。空档听起来像"没人做"，而真实世界里几乎没有纯粹的没人做——多半是"有一两篇苗头、还没形成气候"，这才叫窗口。实测跑出来的三条（每条都标了数据依据和已有的先行者）：

1. **轻量化和多模态刚开始合流**——多模态/3D 主力论文（2M3DF、CPIR 等）基本不谈部署开销；48 篇里已有一篇先行者 LPFSTNet（2025，轻量×师生×快速 3D），正是"3D 版 EfficientAD"的路子，但仅此一篇，窗口刚开；
2. **大模型的见识 × 轻量的身板**——零样本方法（IAD-CLIP 等）个个块头巨大；48 篇里已有 SAM-guided 轻量模型（16 引）这个苗头，但"把大模型的见识蒸进小模型"还远没成气候；
3. **应用落地文稀缺**——48 篇里只有 5 篇，方法卷成红海，但"真实产线部署+踩坑"反而少有人写。如果你是有产线数据的工程师，这就是你的门。

这三条的成色不一样，用的时候要分开说：前两条是"趋势判断"——窗口开没开、开多大，是从苗头推的，下结论前要再专门搜一轮确认；第三条是"数出来的分布"——5/48，硬数字，可以直接报。把趋势判断当成硬结论，是新手在组会上翻车的经典姿势。我们自己就差点栽在这：初稿曾写"系统综述 2025 年才出现第一篇"，拷打复核时发现 48 篇里第 34 名就是一篇 2024 年的综述，领域里 2024 年还另有一篇 338 引的高引综述——一句"硬数字"没核到底，组会上遇到读过那篇综述的导师就当场翻车。所以 prompt 里那句"写之前先回文献里查一遍"，是拿自己的教训换的。

从"导师说了个词"到"手握一页有数字撑腰的摸底报告"，实测全程不到 30 分钟。这份报告不能直接当你的选题——窗口是不是真窗口、你的条件够不够得着，要跟导师确认。开口的姿势也给你备好了："老师，我把这个方向近五年高引的 48 篇过了一遍，划出来 6 个流派，外加一批同名不同界的时序论文，年份分布和窗口在这页纸上，我想往第 X 个窗口试试，您看靠谱吗？"——同样是请教，带地图的请教和两手空空的请教，导师给你的时间不是一个量级。

## 四、坑清单

每一条都有出处，不编。

1. **检索词差一点，结果差一城**（实测）。宽搜索 25,331 条（已限定 2021 年起、按引用排），前排全是 6G 和元宇宙；四个词进标题摘要但不带引号，704 条，前排全是网络入侵检测；只搜短语不加搭配词，866 条，榜首换人。只有"完整短语+搭配词"这一种写法把结果收到 269 条、回到本行。发现结果不对劲，第一反应不是换工具，是收紧检索式。
2. **同名不同界**（实测）。"工业异常检测"下混着图像和时序传感两个互不往来的社区，AI 不提醒你就会把两边文献搅在一起引用。让它划流派时这类"假同行"会自己现形。
3. **AI 给的文献必须核真伪**（实测+经验）。让 AI 归类流派时它会想凭印象猜，必须逼它回查原文摘要——EfficientAD 的门派就是查了摘要才定案的。更狠的坑是 AI 徒手"回忆"出根本不存在的文献、或把 A 的成果安到 B 头上（张冠李戴），所以本章从头到尾用真实数据库查询而不是让 AI 背书单。
4. **预印本重复计数**（实测）。同一篇论文的 arXiv 预印本（正式发表前挂网的草稿版）和正式版在数据库里是两条记录，我们抓的 50 条里 PNI 和 EfficientAD 各占了两条。本章第 2 步的 prompt 已经写死了"先去重再统计"；你哪天自己另起炉灶查文献，别忘了这一步，不然所有统计都会虚高。
5. **按引用排序天然亏待新论文**（实测）。2026 年的好论文引用还没长起来，纯引用榜会漏掉它们。摸完引用榜，值得再让 AI 按"最新发表"补拉一把近一年的。
6. **老文献参考力弱**（经验，我们在投稿中栽过）。找写作范文、判断期刊风格时，五年前的老文会把你带偏——期刊版式和写法是会变的，参考文献优先挑近三年。
7. **说"没人做"之前先回自己的数据里查一遍**（实测，本章初稿栽过）。初稿的"综述 2025 年才出现"被拷打员在我们自己的 48 篇里当场抓出反例（第 34 名就是 2024 年综述）。"没人做"是最容易说、也最容易被打脸的一句话——说之前，至少把手里这批文献搜一遍。

## 五、一句带走

**方向不是读出来的，是数出来的。**读 30 篇的人在城里迷路，数 48 篇的人手握地图——而画这张地图，只要你会复制粘贴。

地图到手，下一个问题立刻冒出来：这 48 篇总得有人读吧？下一章告诉你一个更狠的答案：一篇都不用你自己读完。
