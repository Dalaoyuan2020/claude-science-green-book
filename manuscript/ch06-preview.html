一、先找到门：设置在哪儿

提纲：不在顶部菜单，在左下角那个齿轮。点开是个小弹窗，Settings 在里面。找不到门是最常见的第一个卡点。

🔒 发布前要打码：弹窗里露了订阅邮箱 真实订阅邮箱 和 Personal / Max plan。按你说的，现在先不打，定稿时统一处理。

二、进门先认路：左边就两组

提纲：11 个子页看着吓人，软件自己分好了两组 —— 上面 Capabilities（给它加本事）六个，下面 Workspace（管住它的手脚和账本）五个。记住这两个词就不会乱。

三、不想读完？先照这四条设

提纲：全章的钩子，四条改完就能用，其余用到再回来查。这节不配图，就是一张清单。

  1. General → Licensing 改成 Non-commercial
    做科研的必改。不改会触发一堆开源组件的商业授权报错。这条几乎没人讲。
  2. General → Contact email 填上
    它替你爬 NCBI / EBI 时会带上这个身份，不填容易被限流。
  3. Memory → 打开
    默认是关的。记忆存本地，不传给 Anthropic。
  4. Storage → 换到非 C 盘
    回扣 Day 3「C 盘跑爆」。光 Conda 环境一个就 8.3 GB。

四、Capabilities：六个面板，给它加本事

1. Skills —— 给 AI 装特长

提纲：Featured 官方精选、Imported 从 GitHub 导、Personal 自己写。要如实说一句：16 个官方技能全是生物方向的（AlphaFold2、ESM-2、DiffDock、ProteinMPNN…），不做生物的人指望不上，得自己导或自己写。

💡 这是新截图带出来的发现，原稿里没有。我觉得该写，读者不会觉得被忽悠。

2. Connectors —— 直连学术数据库

提纲：bioRxiv / ChEMBL / Clinical Trials / PubMed 这些开关一开，它就能自己去查库。顺带一句真坑：国内网络下 claude.ai 连不上时，整个目录拉不出来，别以为软件坏了。

✂️ 按你第 1 条，联网正常那张不放了，就用这张，坑一句话带过。

3. Specialists —— 换个专业身份

提纲：目前只有一个内置角色 Reviewer。开了它，AI 就用审稿人的苛刻视角看你的稿子。

4. Memory —— 记住你的背景

提纲：右上角总开关默认 Off，记得开。左边可以自己建分类。全部存本地。

5. Compute —— 代码在哪跑

提纲：能接自己的服务器（SSH）、云 GPU（Modal）、专业科学模型（NVIDIA BioNeMo）。默认 Local 最稳，涉密数据别挪。

6. Network —— 镜像和白名单

提纲：上半配包镜像（机构内网用），下半是科研域名白名单。跟 Connectors 那个坑呼应。

✂️ 按你第 4 条，白名单那张不单开一张了，跟这张一起在文字里说完。

五、Workspace：五个面板，管住手脚和账本

7. Permissions —— 它能动你哪些东西

提纲：右边 Revoke all 一键收回。重点提醒一句：bash 调用权限是绑到具体项目上的，不是全局。

🔒 露了 真实项目名。按你之前拍的板，定稿时一起处理。

8. Credentials —— 外部服务的钥匙

提纲：AWS / GitHub / 期刊访问 / OpenAlex 等八个服务的凭据都存这，还能自己加。

9. Storage —— 第三条「换盘」在这操作

提纲：改路径要先关掉活跃会话。看一眼构成就知道为什么必须挪盘：Conda 环境一个 8.3 GB。

10. Usage —— 钱花哪儿了

提纲：环形图看 token 去向。Reviewer 占 47% —— 审查员是最贵的那个开关，这个数字值得单独说一句。

11. General —— 第三条里那两条改在这

提纲：默认模型、推理强度、Licensing、联系邮箱、版本号都在这页。新截图还带出个原稿没有的：Reviewer model 可以单独设（这里是 Sonnet 5），正好接上一节「审查员最贵」—— 想省钱就把它调小。

💡 Reviewer model 也是新图带出来的。它跟 Usage 那个 47% 正好串成一条线：贵 → 可以调 → 在这调。
