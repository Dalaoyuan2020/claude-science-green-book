从最外层，一层层看懂这个软件

一 先问它一句：你到底是什么？

认识一个新工具，最好的开场不是我来讲，是让它自己说。我直接问 Claude Science「你是什么、有什么功能」，它答了这么一段：
图 5-1 · Claude Science 的自我介绍

它把自己定义成一句话：Anthropic 推出的、面向科学研究的 AI 工作平台。不是简单的对话机器人，而是一个自带完整计算环境、能编程执行、能连学术数据库、支持多智能体协作的科研生产力系统，一个会话窗口里就能从数据获取、分析、建模一路做到论文图表。它还当场亮了家底：内置 Python / R / Bash 环境，pandas、numpy、scipy、PyTorch 这些主流科学库开箱即用。

再用大白话兜底：它是一个「会自己动手的科研工作台」，底子是 Jupyter Notebook。

别把它当聊天框，把它当一张桌子：桌上有你的项目、有干活的工作区、有干完的产出。下面就从最外层的「桌面」开始，一层层往里看。

双击进来第一眼看到的，就是这张「大门」，管你有哪些研究、最近在忙什么。

三 进入项目：三栏工作台

点开任意会话，界面变成真正干活的样子：左中右三栏，是你今后花时间最多的地方。

图 5-3 · 项目内三栏工作台
1左栏 · 会话与文件：New 新建会话、Customize 定制、Files 文件、Older 历史。管「这个项目里的事」。
2中栏 · 对话主战场：你发指令、它铺过程。底部有 Reviewer 审查条、Notebook 入口、输入框（@产出物 #会话 /技能 ⌘K 搜索）和模型选择。

🧭 一件研究这样流动：左边挑事情 → 中间干活 → 右边收成品 → 回中间继续提要求。

四 功能菜单：控制 AI 怎么帮你干活的一圈开关

要注意：这圈开关不在顶部，而是围着底部的输入框，很容易被忽略。分两处，共 7 个功能。

第一处 · 输入框正上方的状态行

12
图 5-4 · 输入框上方的状态行（+ 左下 ⊟ 功能按钮）
① active subagents 活跃子智能体看懂即可

复杂任务时后台自动唤醒专业子代理并行干活。数字大于 0 说明在忙重活，别打断；点它能看后台在干嘛。

② Notebook 交互式代码环境建议熟悉

点开在右栏跑 Python/R，AI 画图跑模型直接执行并展示结果，还能核对数值、复用代码。

第二处 · 点 ⊟ 按钮弹出的菜单

输入框左下角那个 ⊟ 按钮（激活时带个小蓝点），点开就是这五个开关：
12345
图 5-5 · 功能菜单弹窗
① Delegation 任务委派按需开

把复杂任务拆成并行轨道。日常问答用不着，大任务再开省时间。

② Auto-review 自动审查建议常开

独立审查员核对「声称 vs 实际记录」：数值对不对得上来源、引用撑不撑得起结论、DOI 是否一致。不重跑分析，但能挡下大量肉眼难发现的错。

③ Memory 记忆建议常开

存论文主题、目标期刊、写作偏好，新对话不必重复交代。存在本机本地库，不同步到 Anthropic。默认关，记得手动开。

④ Specialist 专家角色设一次

技能+连接器+指令打包的具名角色。写方法学选统计学家，审稿切 Reviewer。默认 None，用到再切。

⑤ Compute 计算位置设一次

决定代码在哪跑。默认 Local，未发表数据只在自己电脑上跑，隐私最稳。要大算力再去设置接服务器。

五 再往里：还有一个设置中心

🔧 设置中心（自定义配置）· 本章先点一下，下章讲透

主页、三栏、功能菜单这三层是日常打交道的界面。再深一层是设置中心：点开是一排设置子页（技能、连接器、权限、存储、用量、账号…），每页管一类深度配置。和前面不同，这些子页不带底部那圈功能菜单，因为它们是「配置」的地方、不是「干活」的地方。配一次长期受益，留到下一章专门讲。

六 开机就这么设（小抄）

开关推荐一句话理由
Auto-review✅ 开自动挡错，投稿前的保险
Memory✅ 开不用反复交代背景，本地存储不外传
Notebook熟悉它核对数值、复用代码全靠它
Delegation大任务再开省 token 和响应时间
Subagents看懂即可后台协作的状态灯，别打断
SpecialistNone，用到再切需要专业口吻时才上
ComputeLocal未发表数据不出你的电脑
一句带走

由外到里认准四层：主页挑项目 → 三栏里干活收货 → 输入框那圈七个开关调方式 → 设置中心做深度配置。前三层这章讲完了，先把 Auto-review 和 Memory 打开，你就站在一个靠谱的起点上了。
