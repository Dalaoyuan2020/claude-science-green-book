# Day 1 · 我给科研人找了个不睡觉的科研搭档

> 绿皮书连载 · 第 1 天 · 小驴同学
> 这个系列一天一更，记录我们用 AI 跑通「选题 → 文献 → 写作 → 投稿」全流程的每一步，最后合并成一本免费的《Claude Science 绿皮书》。

## 一、先说这是个什么软件

Claude Code，Anthropic 出的命令行 AI 工具。一句话：**它不是一个聊天框，是一个能替你动手干活的研究助理。**

你可能用过网页版的 ChatGPT 或者 Claude：你问它答，答完的东西你还得自己复制、自己存、自己整理。Claude Code 不一样，它直接住在你的电脑里：

- 你说"帮我查一下这个方向近五年的文献"，它**真的去查**（调学术数据库的接口），查完把结果**存成文件**放在你的文件夹里
- 你说"把这三十篇按流派分个类"，它分完直接给你生成一份报告
- 你说"这份报告排成 PDF"，它连排版都干了

对科研人来说，这个差别是本质的：聊天框帮你**想**，Claude Code 帮你**做**。文献检索、数据整理、格式转换、画图排版，这些不产生任何智力增量、却吞掉你一半时间的活，都是它的菜。

装它只要一条命令（官网 claude.com/claude-code，Windows/Mac 都行），后面每天的连载我们会一步步带着装、带着用。

## 二、送一个我们自己写的 skill：让 AI 帮你查文献

Claude Code 有个机制叫 **skill**（技能包）：把一套干活的流程写成说明书装给它，它就多一门手艺。

今天开源我们自己天天在用的第一个：**paper-search 文献检索技能包**。

它教会 Claude Code 用 OpenAlex 这个免费开放的学术数据库（收录超过 2 亿篇论文，覆盖你熟悉的各大期刊）去查文献、排序、找免费全文。**不要 API key，不要翻墙，不要装任何第三方包，Windows 上直接能跑。**

安装三步：

1. 到我们的 GitHub 仓库下载 `skills/paper-search` 文件夹（地址见文末）
2. 放到 `C:\Users\你的用户名\.claude\skills\` 下面（Mac 是 `~/.claude/skills/`）
3. 打开 Claude Code 说一句："帮我查一下 XXX 方向的文献"

它就会自动用这个技能包干活。查出来的每篇文献带标题、年份、引用数、DOI、有没有免费 PDF。不是编的，是真数据库里拉的。

## 三、丑话说在前面：它很能烧钱

这是今天最重要的一段，比推荐软件重要。

Claude Code 好用的另一面是**消耗量大**。它每替你干一件事，背后都在大量调用模型，而模型按用量计费。官网订阅档位（以官网为准）：Pro 每月 20 美元，重度档 Max 每月 100 或 200 美元。

我们的真实体感：**拿它干科研这种重活（一次读几十篇文献、反复改稿、跑数据），Pro 档一个认真干活的下午就可能碰到用量上限**，得等几个小时恢复。这不是软件的 bug，是它真的在替你干很多活。

所以给三条实在建议：

1. **先用 Pro 档试水**，别一上来就上重度档；摸清自己的用量再升级
2. **让它干"值钱"的活**：文献综述、改稿这种一次省你几小时的事，别拿它闲聊
3. 这个"烧钱焦虑"本身就是个大话题，**后面我们会专门写一篇怎么省着用**，包括哪些活该给贵模型、哪些活给便宜模型就够了

## 四、实测：30 分钟摸清一个陌生方向

光说不练假把式。我们今天用上面这套（Claude Code + paper-search）真跑了一个方向：**轻量化工业异常检测**（给工厂产线的视觉质检 AI"瘦身"）。全程实测于 2026 年 7 月 4 日，每个数字都有原始数据存档，不是编的。

**第一把就翻车了**：直接搜"anomaly detection"，命中 **25,331 篇**。这就是没人带的新手最真实的处境：不是查不到，是查到的根本读不完。

让 Claude 把检索式精修（限定标题摘要含"industrial anomaly detection"、加轻量化相关词、限 2021 年后），命中降到 **269 篇**，按引用取前 50 条记录（去掉预印本重复后是 48 篇，下面统计都按 48 算）分析。然后它交出了四样东西：

**① 年份分布** — 2021 年才 1 篇，2023 年 10 篇，2024 年冲到 21 篇峰值。判读：上升期方向，不是夕阳赛道。

**② 流派地图** — 48 篇自动归成 7 派：重建生成类（9 篇）、记忆库类、师生蒸馏类、多模态 3D、大模型零样本……全场最高引（268 次）是 EfficientAD，"毫秒级延迟"直接写进标题。说明这个领域的军备竞赛已经从"更准"转向"更快更小"。

**③ 期刊主场** — IEEE 工业系 Trans、Neurocomputing、Sensors；但最高引的方法都发在顶会。投稿去哪，一目了然。

**④ 空档提示**（数据显示的，不是拍脑袋）— 比如：48 篇里**应用落地文只有 5 篇**。方法卷成红海，但"真实产线部署+踩坑"的工程文反而稀缺。如果你是有产线数据的非科班读者，这就是你的门。

从翻车到拿到这份摸底报告，**全程约半小时，人只做了两件事：提出方向，和读结论。**

换成传统方式呢？手动检索、挨个点开、Excel 记年份，这是一周的活，而且你八成坚持不到第 50 篇。

> 顺带一个今天实测踩的坑，先记下：AI 给的文献清单里，同一篇论文可能以"预印本+正式版"出现两次（我们抓的 50 条记录里就有 2 条重复），用之前要让它去重核对。AI 报的文献必须核 DOI 真伪，这条铁律后面每天都会重复。
